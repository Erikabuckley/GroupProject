Accessibility Statement

We want to make this game accessible to as many people as possible. If you have any suggestions, you may contact us via our contact info as described below. The page content should be easy to read and understand. You may navigate most of the website using a keyboard. We are continually working on our game to update it so that it fits the needs of anyone regardless of accessibility requirements.

A few key features are listed below:

  • Keyboard navigation
  • Alt text for images
  • Proper markup for content
  • Text reflows
  • High contrast
  • Labels for all input fields
  • Clear fonts for easy readability
  • Clear site organisation

If you find any problems not listed on this statement or think that we are not meeting sufficient accessibility requirements, contact our team through universityreception@exeter.ac.uk and we will be in touch as soon as possible.
