Submission Criteria

Prohibited User Behavior:

  • Hacking: any form of unauthorised access into any part of our application including, but not limited to, exploiting bugs or glitches that disrupt competition; using bots to create false personas; hacking, cheating, or using third-party software to gain an unfair advantage
  • Harassment and Cyberbullying: using threatening language; bullying, harassing or humiliating others
  • Sharing Inappropriate, Harmful or Offensive Content: sexualised, violent, extremist or self-harm related content; promoting drugs, weapons or adult services; encouraging or glorifying real-world violence, suicide or harm
  • Uploading sensitive, copyrighted or AI-generated and/or edited content as a submission for a challenge

Ensure that:

  • The image represents the mission.
  • The image does not include sensitive Personally Identifiable Information (PII). Examples include: passport number, driver's license number, bank account number or biometric records.
  • There is no evidence of AI/editing – image uploaded is not Photoshopped or looks AI-edited. Uploading edited or AI-generated images is against the rules and is clearly stated in the Terms of Service. Deliberately uploading falsified evidence counts as cheating and will result in suspension or banning of the account.

Automated Flagging (by system)

  • File Integrity: If the file uploaded is unreadable, it is flagged as File Corrupted
  • Duplicate Uploads: A unique hash is generated for the image. If the hash matches a previous entry, then it is flagged as Repeat Evidence.
  • Submission Frequency: The timestamp for each submission is stored in the database. If the interval between current submission and previous upload is unreasonably short, it is flagged for suspicious activity. A user having a high frequency of submissions in a short period can signify either bot activity or spam-logging just to get more points.

Manual Flagging (by moderators)

  • Contradictory: The image does not match the mission
  • Sensitive information: The image includes senstivie PII.
  • Fake/AI images: The image is clearly AI generated/edited.
  • Extreme value: unrealistic submission uploaded with an unrealistic quantity e.g. 10000 steps a second.
